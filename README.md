# Sky Spirit Exporter

Минимальная утилита для Windows x64: лаунчер и DLL для экспорта серверного
каталога духов Sky: Children of the Light (Steam).

**Тестовая версия.** Привязки сверены с локальными бинарниками; получение
живого каталога в Windows Sky ещё требует ручной проверки. Наличие DLL/EXE
не означает подтверждённую совместимость с последней версией игры.

## Запуск

1. Скачайте архив из Releases, распакуйте EXE и DLL в одну папку.
2. Запустите Steam Sky и `SkySpiritExporter.exe` с одинаковыми правами.
3. Нажмите **Подключить и экспортировать** перед входом в аккаунт.
4. Войдите в игру. Если вход уже выполнен, откройте магазин духа, чтобы
   игра отправила запрос. Утилита ждёт до двух минут.
5. Полный каталог сохранится в
   `Документы\SkySpiritExport\spirit-catalog-export.json`.
   Путь можно изменить в окне. Предыдущий файл остаётся с суффиксом `.previous`.

Кнопка **Обновить JSON** повторяет чтение. Автообновление опрашивает каталог
раз в пять минут, пока работают Sky и утилита. Утилита сама не входит в аккаунт,
не запускает игру и не обновляет адреса после обновления Sky.
После замены DLL перезапустите Sky: выгрузка активного перехвата не предусмотрена.

## Автоматизация для Sky Studio

```powershell
.\SkySpiritExporter.exe --once --output "C:\SkyStudio\input\spirit-catalog-export.json"
.\SkySpiritExporter.exe --watch 300 --output "C:\SkyStudio\input\spirit-catalog-export.json"
```

При нескольких копиях Sky добавьте `--pid 1234`. Код выхода `0` означает
успешное завершение; `1` — ошибку. Режим `--watch` работает до остановки
или ошибки. При ошибке неполный каталог не заменяет прежний файл.

Формат:

```json
{"version":123,"build":426499,"items":[{"id":1,"nm":"item_name","spirit":"spirit_name","cst":10,"ct":"candles","dep":0,"ap":false}]}
```

Это пример структуры, не реальные игровые данные. Сохраняются только поля
`id`, `nm`, `spirit`, `typ`, `cst`, `dep`, `ap`, `ct`, `currency`, `currency_type`.
Отсутствующая валюта или цена остаётся отсутствующей; значения не угадываются.
`dep` — зависимость узла, `ap` — требование пропуска.
Наличие ветки не подтверждает, что событие сейчас активно. Расписание событий,
иконки и цены магазина Steam/IAP этим проектом не экспортируются.

## Как работает

Лаунчер загружает DLL через `LoadLibraryW`. DLL перехватывает сборку исходящего
запроса в AccountServerClient и извлекает только UUID и токен текущей сессии.
Параметры запроса и ответ игры не изменяются. В локальный канал с ACL текущего
пользователя и SYSTEM передаются только эти два идентификатора и статус сборки;
сетевые клиенты канала запрещены. Лаунчер проверяет PID сервера канала.

Лаунчер отправляет HTTPS POST только на
`https://live.radiance.thatgamecompany.com/account/get_spirit_shops`, используя
текущую сессию. Проверка TLS штатная; сертификаты и настройки игры не меняются.
Пагинация: `l=1000`, `o=<число полученных узлов>`, `v=<версия каталога>`.
Смена сессии, версии/размера каталога, повтор ID и пустая промежуточная страница
останавливают экспорт. Предел — 50 000 узлов. Перед записью поля фильтруются;
JSON записывается через временный файл и атомарную замену.

Ключи аккаунта не читаются. Сессия нужна для запросов и находится только в
памяти DLL/лаунчера; в JSON и диагностический вывод она не записывается.
После выхода из аккаунта сервер может отклонить сохранённую в памяти сессию;
утилита не пытается повторно авторизоваться. Другие моды, перехватывающие ту же
функцию, могут конфликтовать.

## Проверенные статически бинарники

| Sky | SHA-256 Sky.exe | Request queue RVA | Path offset |
| --- | --- | --- | --- |
| 0.34.5 / 410941 | `4514c85f73cfe4b6d7d9910b36585ce5e135cfd3a04167c1dbc88d14ea96dba4` | `0x6ff50` | `0x8e` |
| 0.35.1 / 423272 | `9723e07be346a57e3f99dce52641edc47dcb9b278727e41b459e87c7d9f46567` | `0x707f0` | `0x90` |
| 0.35.2 / 426499 | `bdd780f88a7d34f7c3a9b336e82dc57393c3a8a7f0e639f28c41e709b9134b19` | `0x707f0` | `0x90` |

Неизвестный SHA-256 отклоняется до инъекции. DLL независимо повторяет проверку
хеша и пролога. Это намеренное ограничение: после обновления нужно проверить
ABI и добавить новую привязку в `Bridge.c` и `Launcher.cs`.
Не добавляйте один лишь хеш без анализа нового бинарника.

Во всех трёх проверенных бинарниках: тело запроса — указатель по `body+0x810`,
длина по `body+0x818`; заголовки — до 32 MSVC string-пар с `body+8`, шаг `0x40`,
число по `body+0x808`. Хост читается с `url+8`. В новых версиях путь сдвинут:
это сверено по инструкциям сравнения `/` в функции очереди. Бинарники игры
в репозиторий не включены.

## Сборка

Windows: Visual Studio 2022 Build Tools, C++ x64, .NET Framework 4.8.
В x64 Native Tools Command Prompt:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Результат — `dist/SkySpiritExporter.exe` и `dist/SkySpiritBridge.dll`.
GitHub Actions выполняет такую же сборку и тесты.
`build.sh` — дополнительная сборка на Linux с Clang/LLD, Wine headers и Wine Mono.

Тесты проверяют границы извлечения идентификаторов, пагинацию, смену сессии,
изменение каталога, повтор ID, неполные ответы, исключение секретных полей и
сохранение предыдущего файла. Они не заменяют проверку в игре.

Ориентир для PC HTTP ABI:
[thatskymod/frida_sky_http_hook.js](https://github.com/thatskymod/Sky-CotL-Scripts/blob/main/PC/Utils/frida_sky_http_hook.js).
Код Frida не требуется и не включён. MinHook 1.3.4 включён с собственной лицензией
в `vendor/minhook/LICENSE.txt`. Остальной код проекта — MIT.
