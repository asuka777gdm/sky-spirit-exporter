# Дерево духов — мод для Windows Sky

Полный комплект для Steam Sky: загрузчик, одна DLL мода и русская панель
экспорта дерева духов. Ничего не нужно запускать вручную после установки.

**Тестовая версия:** сборка и автоматические проверки не заменяют проверку
в настоящей игре. Привязки рассчитаны на точные бинарники в таблице ниже.
Если сборка Sky неизвестна, мод покажет сообщение и не установит перехват.

## Установка за один раз

1. Скачайте **SkySpiritExporter-v0.2.0-full-windows-x64.zip** в
   [Releases](https://github.com/asuka777gdm/sky-spirit-exporter/releases/tag/v0.2.0).
2. Полностью закройте Sky.
3. В Steam: **Библиотека → Sky → шестерёнка → Управление → Просмотреть локальные файлы**.
4. Распакуйте содержимое архива в открытую папку, рядом с `Sky.exe`.
5. Получится такая структура:

```text
Sky.exe                      ← уже установленная игра
steam_api64.dll              ← уже установленный файл Steam
dxgi.dll                     ← загрузчик из архива
mods/
    SkySpiritBridge.dll      ← мод из архива
```

В архиве нет Sky.exe: файл игры не заменяется. Если рядом со Sky.exe уже есть
`dxgi.dll` от другого загрузчика или ReShade, **не перезаписывайте его**:
этот комплект рассчитан на установку без другого DXGI-загрузчика.

## Как пользоваться

1. Запускайте Sky обычным способом через Steam.
2. Панель **«Дерево духов»** откроется автоматически.
3. Войдите в аккаунт. Если кнопка ещё серая, откройте магазин любого духа в игре.
4. Нажмите **«Экспорт дерева духов»**.
5. Получите файл:

```text
Загрузки\sky-spirit\spirit-catalog-export.json
```

Точный путь показан в панели. Кнопка **«Открыть папку JSON»** открывает эту папку.
Прежний JSON сохраняется рядом как `spirit-catalog-export.json.previous`.
Экспорт — это получение данных из игры в файл; импорт в Sky Studio выполняется
самой Sky Studio. Настройки её импорта мод не меняет.

**F8** показывает или скрывает панель. Крестик скрывает её до следующего F8.
Когда Sky закрывается, панель завершается сама.
Это отдельная небольшая панель поверх игры, а не новый пункт штатного игрового
меню. Для работы поверх игры используйте оконный режим без рамки.
Если F8 занят другой программой, оставьте панель на панели задач.

Можно включить **«Обновлять каждые 5 минут»**. Для чтения нужен вошедший аккаунт;
автоматический вход мод не выполняет.

## Обновление и удаление

После обновления мода закройте Sky и замените `mods\SkySpiritBridge.dll`.
Если новый выпуск содержит изменение загрузчика, замените также `dxgi.dll`.
Обновление игры само по себе не обновляет привязки мода: для нового SHA-256
нужна проверенная DLL из нового выпуска.

Для удаления закройте Sky и удалите только установленные этим комплектом
`dxgi.dll` и `mods\SkySpiritBridge.dll`. Экспортированные JSON останутся.
Служебная панель хранится в `%LOCALAPPDATA%\SkySpiritExport\0.2.0`;
при желании эту папку можно удалить после закрытия Sky.

## Что экспортируется

Духи и ветки событий, доступные в серверном каталоге, с ценами, валютой,
зависимостями и требованием сезонного пропуска. Иконки, расписание событий
и реальные денежные цены Steam/IAP не входят в этот экспорт.
Наличие ветки не подтверждает активность события или доступность покупки.

```json
{"version":123,"build":426499,"items":[{"id":1,"nm":"item_name","spirit":"spirit_name","cst":10,"ct":"candles","dep":0,"ap":false}]}
```

Это пример, не игровые данные. Вывод содержит только публичные поля
`id`, `nm`, `spirit`, `typ`, `cst`, `dep`, `ap`, `ct`, `currency`, `currency_type`.
Отсутствующая валюта или цена не угадывается.

## Устройство комплекта

`dxgi.dll` — собственный небольшой загрузчик: он перенаправляет пять экспортов
DXGI в системную `%SystemRoot%\System32\dxgi.dll`, а на рабочем потоке загружает
только `mods\SkySpiritBridge.dll`. Поддерживаемые бинарники Sky импортируют
`CreateDXGIFactory2`. Это не универсальный загрузчик любых модов.

DLL содержит панель как ресурс; распаковывает её в локальные данные пользователя,
сравнивает SHA-256 файла с ресурсом и запускает для PID игры. При таком запуске
повторной инъекции нет. Каталог «Загрузки» определяется через Windows Known Folders,
поэтому учитывается перенос папки. Панель требует .NET Framework 4.8.

DLL перехватывает сборку исходящего запроса AccountServerClient и извлекает только
UUID и токен текущей сессии. Запросы игры не изменяются. Локальный канал разрешён
текущему пользователю и SYSTEM, сетевые клиенты запрещены; панель проверяет PID
сервера. Ключи аккаунта не читаются, сессия не записывается в JSON или логи.

Панель отправляет HTTPS POST только на
`https://live.radiance.thatgamecompany.com/account/get_spirit_shops`.
TLS-проверка штатная, сертификаты не меняются. Пагинация: `l=1000`,
`o=<получено узлов>`, `v=<версия>`. Смена сессии, версии/размера каталога,
повтор ID, неполный ответ или превышение 50 000 узлов отменяют экспорт.
Файл записывается через атомарную замену после фильтрации полей.

Для разработчиков отдельный EXE по-прежнему поддерживает `--once`, `--watch`,
`--pid` и `--output`. В полном установочном архиве EXE не требуется.

## Проверенные статически бинарники

| Sky | SHA-256 Sky.exe | Request queue RVA | Path offset |
| --- | --- | --- | --- |
| 0.34.5 / 410941 | `4514c85f73cfe4b6d7d9910b36585ce5e135cfd3a04167c1dbc88d14ea96dba4` | `0x6ff50` | `0x8e` |
| 0.35.1 / 423272 | `9723e07be346a57e3f99dce52641edc47dcb9b278727e41b459e87c7d9f46567` | `0x707f0` | `0x90` |
| 0.35.2 / 426499 | `bdd780f88a7d34f7c3a9b336e82dc57393c3a8a7f0e639f28c41e709b9134b19` | `0x707f0` | `0x90` |

Неизвестный SHA-256 отклоняется до инъекции. DLL независимо повторяет проверку
хеша и пролога. Это намеренное ограничение: после обновления нужно проверить
ABI и добавить новую привязку в `Bridge.c` и `Launcher.cs`.
Не добавляйте один лишь хеш без анализа нового бинарника.

Во всех трёх проверенных бинарниках: тело запроса — указатель по `body+0x810`,
длина по `body+0x818`; заголовки — до 32 MSVC string-пар с `body+8`, шаг `0x40`,
число по `body+0x808`. Хост читается с `url+8`. В новых версиях путь сдвинут:
это сверено по инструкциям сравнения `/` в функции очереди. Бинарники игры
в репозиторий не включены.

## Сборка

Windows: Visual Studio 2022 Build Tools, C++ x64, .NET Framework 4.8.
В x64 Native Tools Command Prompt:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Результат — `dist/dxgi.dll`, `dist/SkySpiritBridge.dll` со встроенной панелью и отдельный `dist/SkySpiritExporter.exe` для ручного режима.
`python package.py` создаёт полный архив для установки.
GitHub Actions выполняет такую же сборку и тесты.
`build.sh` — дополнительная сборка на Linux с Clang/LLD, Wine headers и Wine Mono.

Тесты проверяют границы извлечения идентификаторов, пагинацию, смену сессии,
изменение каталога, повтор ID, неполные ответы, исключение секретных полей и
сохранение предыдущего файла. Они не заменяют проверку в игре.

Ориентир для PC HTTP ABI:
[thatskymod/frida_sky_http_hook.js](https://github.com/thatskymod/Sky-CotL-Scripts/blob/main/PC/Utils/frida_sky_http_hook.js).
Код Frida не требуется и не включён. MinHook 1.3.4 включён с собственной лицензией
в `vendor/minhook/LICENSE.txt`. Остальной код проекта — MIT.
