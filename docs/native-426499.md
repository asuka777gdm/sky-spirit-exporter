# Native Windows profile: 0.35.2 / 426499

Executable SHA-256: bdd780f88a7d34f7c3a9b336e82dc57393c3a8a7f0e639f28c41e709b9134b19.
The native release enables only this exact profile.

Read-only session sampling uses the same design as Rund CurrentAccount.
Windows fields were independently corroborated:

- Game::Update RVA 0x116fe00, verified 16-byte prologue:
  55 56 57 53 48 81 ec f8 09 00 00 48 8d ac 24 80.
- Game + 0x1c0: AccountServerClient, from the build-pinned Game reflection initializer.
- Game + 0x1d8: AccountBarn; +0x14b4 state must be 0x1c.
- Client + 0x2c0: 16-byte user UUID; +0x2d0: 16-byte session.
  Windows function 0x1419d5120 serializes both into authenticated requests.
- UUID formatter 0x1400f3a60 uses sequential bytes; session formatter
  0x140e8cb00 emits 32 lowercase hexadecimal characters.
- Client + 0x10: HTTP queue. Queue +0x14: bounded 128-byte User-Agent.
  The HTTP queue function at 0x1400707f0 passes it to the header appender
  0x140072200 as the User-Agent header.

No login calls, key reads, purchases, memory edits to account state or session
creation are performed. The hook calls the original update and then reads a
stable double snapshot. A change or loss of session invalidates in-flight reads.
Only /account/get_spirit_shops is requested, using the game's existing User-Agent.
Only allowlisted catalog fields may reach disk.

Earlier version failures:

- HTTP URL host moved from +8 to +0xA in 423272/426499; the path moved
  from +0x8e to +0x90. The old host filter discarded authenticated requests.
  The native release no longer depends on the request hook.
- The earlier client used SkySpiritExport/0.3.0 as User-Agent and a live
  request received HTTP 418. The corrected transport copies the real game agent.
- The old pipe guard merged API failure with PID mismatch into one error.
  A basic Wine PID probe passed, so that particular user's pipe failure was
  not independently reproduced. Native 0.3.0 has no pipe, EXE or .NET runtime.

Never enable a new build by changing only its version/hash. Verify the update
ABI, account fields and formatter before adding a profile.

Catalog schema verified against live responses: currency is `ctyp` (not `ct`).
Public metadata `evn`, `ta`, `tt`, `to`, `td` is preserved. Live pagination
returned version 430536, 2521 unique nodes and 235 spirits.
Icons resolve from local OutfitDefs/CollectibleDefs and UIPackedAtlas regions;
BC4 KTX atlases are decoded locally. Game images are not redistributed.
Snapshot comparison ignores derived icon metadata and handles migration from
older caches without marking every row changed solely for newly retained fields.
