ДЕРЕВО ДУХОВ — полный комплект для Windows x64, версия 0.2.0

УСТАНОВКА
1. Закройте Sky полностью.
2. Steam → Библиотека → Sky → шестерёнка → Управление → Просмотреть локальные файлы.
3. Скопируйте сюда dxgi.dll и папку mods из этого архива, рядом с Sky.exe.
   Должно получиться:
       папка игры\Sky.exe
       папка игры\dxgi.dll
       папка игры\mods\SkySpiritBridge.dll
4. Запустите Sky через Steam. Отдельный лаунчер запускать не нужно.

Если в папке игры уже есть dxgi.dll, не заменяйте его этим файлом.
Комплект рассчитан на игру без другого DXGI-загрузчика/ReShade.

ЭКСПОРТ
1. Панель «Дерево духов» откроется сама. F8 — показать/скрыть.
2. Войдите в аккаунт. Если кнопка серая — откройте магазин любого духа.
3. Нажмите «Экспорт дерева духов».
4. JSON появится в Загрузки\sky-spirit\spirit-catalog-export.json.
   Кнопка «Открыть папку JSON» открывает нужную папку.

Панель отдельная, поверх игры. Рекомендуется оконный режим без рамки.
Крестик скрывает панель, F8 открывает снова. При выходе из Sky она закроется.
Предыдущий файл сохраняется рядом с окончанием .previous.

ПОДДЕРЖКА
Привязки: Sky 410941, 423272, 426499, только точные проверенные SHA-256.
Новая версия Sky может потребовать обновлённую DLL мода.
Требуется .NET Framework 4.8. Проверка в настоящей игре выполняется вручную.
Расписание событий, картинки и реальные денежные цены Steam/IAP не экспортируются.

УДАЛЕНИЕ
Закройте Sky. Удалите dxgi.dll и mods\SkySpiritBridge.dll, установленные этим архивом.
JSON в Загрузках останутся.

Исходники и обновления: https://github.com/asuka777gdm/sky-spirit-exporter
