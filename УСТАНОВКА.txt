ДЕРЕВО ДУХОВ — нативный мод 0.3.0 для Sky Windows x64

1. Закройте Sky полностью.
2. Steam → Sky → Управление → Просмотреть локальные файлы.
3. Распакуйте архив в эту папку:
       Sky.exe                       (уже установленная игра)
       powrprof.dll                  (из архива)
       mods\SkySpiritBridge.dll     (из архива)
4. Запускайте Sky через Steam. Отдельный EXE не нужен.
5. Войдите в аккаунт. Дерево загрузится автоматически.
6. Выберите духа. «Экспорт JSON» сохраняет полный каталог в:
       Загрузки\sky-spirit\spirit-catalog-export.json

Новые/изменённые/удалённые предметы сравниваются с предыдущим каталогом.
При первой загрузке все предметы считаются исходной базой.
Есть фильтры типов и событий, поиск, дерево/список и сортировка списка.
Иконки берутся из установленной игры; служебные узлы могут иметь значок категории.
Валюты читаются из серверного поля ctyp.

F8 — скрыть/показать. Панель можно двигать за верхнюю полосу.
«Папка» открывает каталог экспорта. Прежний JSON получает суффикс .previous.
Поддерживается точная сборка Sky 0.35.2 / 426499 (хеш указан в README).
После обновления игры может потребоваться новая DLL мода.

ПЕРЕХОД С ВЕРСИИ 0.2.0
Удалите старый dxgi.dll именно от нашего экспортера. Новый загрузчик — powrprof.dll.
Чужие DLL не перезаписывайте. Если powrprof.dll уже от другого мода,
эта установка без согласования загрузчиков не подходит.

LINUX / PROTON
Параметры запуска Steam: WINEDLLOVERRIDES="powrprof=n,b" %command%

УДАЛЕНИЕ
Закройте Sky. Удалите установленные этим комплектом powrprof.dll и
mods\SkySpiritBridge.dll. Экспортированные JSON сохранятся.
